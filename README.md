# Banking Backend

## Start

Use the `Dockerfile` file to build and run this application part.

And expose container port 8080 to the host.

## Routes

- `<base-url>/swagger-ui/index.html` for the Swagger documentation
- `<base-url>/h2-console/` to execute database requests
